# RELiV Product Workflow

## Product journey

```text
PATIENT
   │
   ▼
RELiV KIOSK
   │
   ├───────────────┐
   ▼               ▼
HEALTH SCREEN    PURCHASE
   │               │
   ▼               ▼
WELLNESS         PAYMENT
ANALYSIS       VERIFICATION
   │               │
   ▼               ▼
DIGITAL REPORT   AUTHORIZATION
   │               │
   ▼               ▼
QR / DIGITAL     KIOSK CHECK
DELIVERY           │
                   ▼
               DISPENSING
                   │
                   ▼
                RECEIPT
```

## Health screening

```text
Patient → Start session → Capture measurements → Process locally → Generate wellness summary → QR / digital delivery
```

## Essential purchase

```text
Select item → Payment → Server verification → Signed one-use authorization → Local verification → Dispense → Digital receipt
```

## Product principles

- Simple, guided interaction
- Local-first kiosk operation
- Clear separation between screening and dispensing
- Explicit payment verification before fulfillment
- Digital-first reports and receipts
- Validation and professional follow-up for health concerns
