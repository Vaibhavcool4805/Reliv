# Security Policy

## Scope

RELiV is an evolving healthcare kiosk prototype. Security-sensitive areas include payment verification, kiosk authorization, device communication, local storage, and handling of health-related data.

## Reporting a vulnerability

Please do not publish exploitable security details in a public issue. Contact the project maintainers privately with a clear description, reproduction steps, affected component, and potential impact.

## Prototype notice

The current project is not represented as a clinically validated or production-ready healthcare system. Security controls described in the architecture are engineering targets and require end-to-end validation before broader deployment.

Never commit API keys, payment credentials, device passwords, private patient information, or production secrets to this repository.
