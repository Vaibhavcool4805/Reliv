# Contributing to RELiV

Thank you for your interest in improving RELiV.

## Areas where contributions help

- Frontend and accessibility improvements
- Backend and session logic
- Raspberry Pi integration
- ESP32 firmware
- Sensor validation and testing infrastructure
- AI/report-processing experiments
- Documentation and diagrams
- Reliability and security testing

## Workflow

1. Open an issue describing the change when the work is substantial.
2. Create a focused branch.
3. Keep changes small and clearly documented.
4. Never commit secrets or real patient information.
5. Test hardware-facing changes carefully before deployment.
6. Open a pull request with a concise explanation and test notes.

## Healthcare responsibility

RELiV is a prototype. Contributions that affect health measurements, medical claims, payment authorization, medicine dispensing, or personal data should include validation notes and clearly state their limitations.
